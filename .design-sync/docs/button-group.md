Groups adjacent buttons into a single segmented control; children are Button elements, optionally split with ButtonGroupSeparator or labeled with ButtonGroupText.

Parts: `ButtonGroup`, `ButtonGroupSeparator`, `ButtonGroupText`

```tsx
<ButtonGroup>
  <Button variant="outline">Day</Button>
  <Button variant="outline">Week</Button>
  <ButtonGroupSeparator />
  <Button variant="outline">Month</Button>
</ButtonGroup>
```
